# Library Management System

The **Library Management System** is a simple C# console application designed to manage library items such as **Books** and **Magazines**. The project demonstrates fundamental programming concepts including **Object-Oriented Programming (OOP)**, **inheritance**, **abstraction**, and **exception handling** in C#.

The system allows users to add new books and magazines, remove items by title, and display all items stored in the library. It also includes input validation to ensure that data such as title, publisher, and publication year are entered correctly. Custom exceptions are used to handle invalid data and prevent duplicate entries, improving the reliability of the system.

The project is structured into different components such as **Models**, **Services**, and **Custom Exceptions**, making the code more organized and maintainable. Additionally, a **Jenkinsfile** is included to demonstrate basic CI/CD integration.

This project is useful for beginners learning C#, console applications, and basic software architecture practices.
